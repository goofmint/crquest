# フォークとは？

この目標を達成するには、オープンソースの git リポジトリを[フォーク](https://help.github.com/en/articles/fork-a-repo)してください。練習用に [Open Pixel Art](https://github.com/twilio-labs/open-pixel-art) というプロジェクトを用意しました。

自分の GitHub アカウントに [Open Pixel Art](https://github.com/twilio-labs/open-pixel-art) を[フォーク](https://help.github.com/en/articles/fork-a-repo)したら、*ハック* をクリックしてください。リポジトリやフォークの仕組みを詳しく知りたい場合はヘルプを参照してください！
