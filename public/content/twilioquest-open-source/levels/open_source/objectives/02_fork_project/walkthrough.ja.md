# フォークしよう

## フォークとは？

フォークは、ほかの人のリポジトリを自分用にコピーしたものです。元のリポジトリに影響を与えず、自由に変更できます。自分の用途に合わせて調整したり、元のプロジェクトに変更を提案したりするときに使います。

プロジェクトによっては、ライセンスでできることが制限されています。GitHub に[ライセンスを理解するための資料](https://help.github.com/en/articles/licensing-a-repository)があります。

## Open Pixel Art

今回フォークするのは、このミッションのために作った Open Pixel Art リポジトリです。[実際のページを見る](https://open-pixel-art.com)ことができます。ページ上の各ピクセルは、このコースに取り組んだ人が置いたものです。まもなく、あなただけのピクセルを追加する方法を学びます！

## フォークから始めよう

まずはフォークの作り方を学びましょう！ GitHub には手順がわかりやすくまとまった[フォークのドキュメント](https://help.github.com/en/articles/fork-a-repo#fork-an-example-repository)があります。

GitHub の説明にはサンプルリポジトリが挙げられていますが、このミッションでは [Open Pixel Art リポジトリ](https://github.com/twilio-labs/open-pixel-art)をフォークしてください。

## 結果を確認しよう

フォークの意味と作り方がわかったら、実際にフォークしましょう。Open Pixel Art リポジトリをフォークしたら、`HACK` をクリックしてください。フォークの名前は `open-pixel-art` にしてください。
