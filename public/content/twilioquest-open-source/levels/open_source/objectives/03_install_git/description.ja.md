# Git をセットアップしよう

この課題を達成するには、コンピューターに [Git のコマンドラインツールをインストール](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)します。インストール後は、PowerShell や Terminal などのターミナルアプリから `git` コマンドを使えるようになります。

```bash
git --version
```

`git` をインストールして[システムパス](<https://en.wikipedia.org/wiki/PATH_(variable)>)から実行できることを確認したら、`git` の場所を TwilioQuest に知らせます。

コンピューター上にインストールされた `git` コマンドの**完全なパス**を貼り付けます。探し方がわからない場合はヘルプを参照してください。右の入力欄にパスを貼り付け、_ハック_ ボタンをクリックしてください。
