# プルリクエストを作ろう

次は、[プルリクエスト](https://help.github.com/en/articles/about-pull-requests)を作って、プロジェクトに変更を提案します。GitHub でプルリクエストを作成すると__番号__が割り当てられ、URL の末尾に表示されます。

```bash
https://github.com/twilio-labs/open-pixel-art/pull/<PULL_REQUEST_NUMBER>
```

[こちらでオープン中のプルリクエストをすべて確認できます](https://github.com/pulls)。右の入力欄にプルリクエストの番号を入力し、*ハック* をクリックしてください。
