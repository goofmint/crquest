# GitHub アカウントを作ろう

## GitHub とは？

GitHub はインターネット上でオープンソースのコードを公開できるウェブサイトです。世界中の開発者が離れた場所から協力できます。コードを共有する仕組みに `git` が使われています。後の課題で詳しく学びます。

## GitHub に登録する

GitHub の登録手順に従って[新しいユーザーアカウントを作成](https://github.com/join)してください。この目標には無料プランだけで十分です。オープンソースの開発をするなら無料プランで作業できます。

アカウントを作成すると、メールアドレスの確認を求めるメールが届きます。案内に従って確認を済ませると、GitHub アカウントを使えるようになります！

## バリアをハックしよう

アカウントの確認が済んだら、選んだユーザー名を右側の入力欄に入れ、`HACK` を押してください！
