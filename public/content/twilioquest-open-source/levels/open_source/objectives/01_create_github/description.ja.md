# Git を始めよう

多くのオープンソースプロジェクトやソフトウェア企業では、[バージョン管理](https://en.wikipedia.org/wiki/Version_control)や共同作業に [git](https://git-scm.com/) を使います。[GitHub](https://www.github.com/) は、多くのオープンソースプロジェクトが [git リポジトリ](https://git-scm.com/book/en/v1/Git-Basics-Getting-a-Git-Repository)を置くために使うプラットフォームです。

これからの課題では、GitHub 上のオープンソースプロジェクトに貢献する手順を体験します。まずは[無料の GitHub アカウントを作成](https://github.com/join)します。

アカウントを作成したら、__選んだユーザー名を右の入力欄に入力__し、*ハック* を押してください。
