# フォークにプッシュしよう

変更を提出する前に、__開発ブランチをリモートにプッシュ__します。プッシュ先は [GitHub 上のプロジェクトの自分のフォーク](https://github.com/<%= env.TQ_GITHUB_USERNAME.value %>/open-pixel-art)です。作業をバックアップする方法としても役に立ちます！

`<%= env.TQ_OPEN_PIXEL_ART_BRANCH.value %>` ブランチを[自分のフォーク](https://github.com/<%= env.TQ_GITHUB_USERNAME.value %>/open-pixel-art)にプッシュしたら、*ハック* をクリックしてください。
