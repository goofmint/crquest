# フォークをクローンしよう

この課題を達成するには、Open Pixel Art プロジェクトの自分のフォークを[クローン](https://git-scm.com/docs/git-clone)します。フォークの名前を変更していなければ、場所は次のとおりです。

[https://github.com/<%= env.TQ_GITHUB_USERNAME.value %>/open-pixel-art](https://github.com/<%= env.TQ_GITHUB_USERNAME.value %>/open-pixel-art)

[リポジトリをクローン](https://git-scm.com/docs/git-clone)すると、コードのコピーが自分のコンピューターにダウンロードされます。コードを含むフォルダーの__完全なファイルパス__を右の入力欄に入れ、*ハック* をクリックしてください。
