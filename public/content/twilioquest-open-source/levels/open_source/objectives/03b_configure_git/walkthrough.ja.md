# Git の設定

## どう設定する？

Git のグローバル設定ファイルは、ターミナルで `git config` コマンドを使って編集できます。作業方法に合わせて Git をカスタマイズする項目がいろいろあります。

このミッションで `git` を GitHub と一緒に使うために必要な設定は、グローバルのユーザー名とメールアドレスの2つです。次のコマンドで設定します。すべての `git` プロジェクトで同じ名前とメールアドレスを使うため、`--global` フラグを指定します。

## コマンドを実行しよう

実行する前に `John Doe` を自分の名前に置き換えます。引用符は残してください。

```
git config --global user.name "John Doe"
```

次のコマンドを実行する前に、`johndoe@example.com` を GitHub に登録したメールアドレスに置き換えます。

```
git config --global user.email johndoe@example.com
```

## 設定を確認しよう

すべて正しく設定できたか確認するため、次のコマンドを実行します。

```
git config --list
```

`user.name` と `user.email` に正しい値が設定されているはずです。

## ハックしよう

Git が正しく設定できたことを確認したら、`HACK` を押してください！
