# Git のログを見る

## コミットハッシュとは？

Git は、コードのスナップショットをコミットの一覧として記録します。この一覧はリポジトリの `git history`（履歴）です。各スナップショットを後で見つけられるように、`commit hash`（コミットハッシュ）という長い一意の文字列が割り当てられます。

## Git の履歴

ターミナルで `git log` を実行すると、リポジトリ内のすべてのコミットが表示されます。最新のコミットから最初のものまで、矢印キーで上下に移動できます（`scroll up and down this list with your arrow keys`）。Q キーを押すと表示を終了します（`exit this view by hitting the Q`）。

## ログを絞り込む

履歴のコミットをすべて確認するのは大変で、効率的ではありません。`git log` には、表示する結果を絞り込むための[さまざまなオプション](https://git-scm.com/docs/git-log)があります。

## 自分のコミットだけを見る

ピクセルを追加したコミットを探すために、`--author` フラグを使いましょう！

`git log` のオプションの一つで、指定した作者のコミットだけに絞り込めます。次のコマンドで自分のコミットだけを表示してください。

```
git log --author="<%= env.TQ_LOCAL_GIT_USER_NAME.value %>"
```

## 自分のハッシュを見つける

作者を指定して `git log` を実行すると、作者、日付、メッセージなどの情報が表示されます。コミットの先頭に `b256b5e67556d331ca6876d137db4f61a1eb031a` のような長い文字列が出ます。これがコミットハッシュです！

## 確認しよう

ピクセルを追加したコミットのハッシュを右の入力欄に貼り付け、`HACK` を押してください！
