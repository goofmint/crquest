# プルリクエストのマージ

オープンソースへの貢献の最後のステップは、プルリクエストをマージしてもらうことです。貢献先のリポジトリのメンテナーと協力します。プルリクエスト上でコメントを交わし、メンテナーが納得できる状態になるまでコードを更新します。

Open Pixel Art のプルリクエストは、いくつかのツールで自動処理されます。問題があればボットがプルリクエストにコメントし、修正を求めます。

[自分のプルリクエスト](https://github.com/twilio-labs/open-pixel-art/pull/<%= env.TQ_OPEN_PIXEL_ART_PR_NUMBER.value %>)が自動でマージされたら、左の `HACK` をクリックして宝箱を開けてください！
