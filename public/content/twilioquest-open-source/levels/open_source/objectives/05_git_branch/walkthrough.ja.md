# ブランチ

ブランチとは、別の道筋をたどれる履歴のようなものです。新しいブランチを作った直後は、元と同じコードが入っています。その後に行う変更は、新しいブランチ**だけ**に記録されます。

コードを永久に壊す心配をせず、安心して変更を試せます。ブランチはいくつでも作れますが、この目標では一つだけ作ります。

## 新しいブランチはどう作る？

`git branch` コマンドで、git リポジトリに新しいブランチを作ります。コマンドの例を次に示します。`<BRANCH_NAME>` を作成したいブランチ名に置き換えてください。

ブランチの内容が伝わる名前を付けると便利です。このミッションでは新しいピクセルを追加するので、たとえば `new-pixel` と名付けられます。

```
git branch <BRANCH_NAME>
```

新しいブランチを作ったら、作成を確認するためリポジトリ内のブランチを一覧表示します。

```
git branch
```

ターミナルに、作成したブランチ名を含む一覧が出ます。`master` という別のブランチもあるはずです。

## master とは？

すべての git リポジトリには少なくとも一つのブランチがあります。このミッションで扱う既定のブランチは、慣例に従って `master` と呼ばれます。通常はプロジェクトの最新の安定版です。新機能は今回作ったような別ブランチで開発し、その後 master にまとめます。

ブランチ一覧では、master の横にアスタリスク `*` が付いています。現在の作業先が `master` ブランチという意味です。Git では選択中のブランチを「チェックアウトされている」と表現します。

## 新しいブランチに移動するには？

現在は `master` ブランチで作業しているとわかったので、新しいブランチをチェックアウトしましょう。

`checkout` コマンドでブランチを切り替えます。次のコマンドの `<BRANCH_NAME>` を新しいブランチ名に置き換えてください。

```
git checkout <BRANCH_NAME>
```

後で master やほかのブランチに戻りたい場合は、別のブランチ名を指定して `git checkout` を実行します。

```
git checkout master
```

## 確認しよう

新しいブランチを作り、チェックアウトできたはずです。次の目標では、このブランチでコードを変更します。ここでは右の入力欄にブランチ名を入れ、`HACK` をクリックしてください！
