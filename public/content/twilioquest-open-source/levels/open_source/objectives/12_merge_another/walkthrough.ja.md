# 別のプロジェクトにも貢献しよう

## プロジェクトを見つけるには？

もっと多くのオープンソースプロジェクトに貢献したいと思うことは、よい第一歩です。では、どうやって貢献先を探せばよいでしょう？

お気に入りのツールやライブラリ、ソフトウェアがあれば、GitHub のページで未解決の Issue を探してください。プルリクエストを歓迎するプロジェクトは多いですが、今も活発にメンテナンスされているか確認しましょう。

特に思いつかないときは、次の紹介サイトを見てみましょう。それぞれのサイトが、取り組みやすい GitHub の Issue を違う方法で紹介しています。

- [Up For Grabs](https://up-for-grabs.net/)
- [GitHub Trending](https://github.com/trending)
- [First Timers Only](https://www.firsttimersonly.com/)
- [Your First PR](https://yourfirstpr.github.io/)
- [Awesome For Beginners](https://github.com/mungell/awesome-for-beginners)

詳しくは[オープンソースへの貢献ガイド](https://opensource.guide/how-to-contribute/)を参照してください。Issue の探し方や、メンテナーとのやり取りのコツが載っています。コードを書く以外の貢献方法も紹介されています。

## 貢献できたことを確認しよう

次のプルリクエストを作ってマージされたら、XP を受け取るために報告しましょう！

プルリクエストの URL から次の3つの情報を確認してください。

- 貢献先リポジトリの所有者
- 貢献先リポジトリの名前
- 自分が作成したプルリクエストの番号

たとえば Open Pixel Art プロジェクトの場合、次のようになります。

- twilio-labs
- open-pixel-art
- <%= env.TQ_OPEN_PIXEL_ART_PR_NUMBER.value %>

## ハックしよう

右の入力欄に値を入れ、`HACK` を押して XP を受け取ってください！
