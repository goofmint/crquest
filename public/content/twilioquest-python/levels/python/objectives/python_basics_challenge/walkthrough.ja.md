# 思いがけない挑戦

儀式の間の崩れたくぼみに隠し宝箱を見つけました。これまでと同じような錠前で閉ざされています。市民の試練の一部ではなさそうですが、中には貴重な報酬があるかもしれません。

近くにトレドの調査ノートはありませんが、破れた巻物に [Python 公式のクラス作成の解説](https://docs.python.org/3/tutorial/classes.html) への参照がありました。「目標」タブの課題を解く手がかりはこれだけです。

クラスについては今後もっと詳しく学べそうなので、すぐに宝箱を開ける必要はなさそうです。とはいえ、好奇心には勝てないことがあります。

## 取りかかる

指示に従い、次のコード用フォルダーに `citizen.py` を作ります。

```bash
<%= env.TQ_PYTHON_CODE_PATH.value %>
```

これまでの知識を頼りにコードを書いてみましょう。準備ができたら「ハック」を押し、正しく動くか確認します。
