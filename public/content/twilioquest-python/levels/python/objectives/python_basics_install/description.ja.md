# インストールの試練

古代都市 Python の市民を志す人は、現代の開発者と同じように、パソコンへの **Python 3 のインストール**から始めました。[Windows Store（Windows の場合に推奨）](https://www.microsoft.com/en-us/p/python-37/9nj46sx7x90p) または [python.org](https://www.python.org/downloads/) から入手できます。

インストールしたら **`python3` 実行ファイルのフルパス**を調べましょう。手順やパスの確認方法が分からない場合は、この課題の「ヘルプ」を読んでください。

フルパスを右の入力欄に貼り付けてください。有効なインストールを確認できれば、試練を達成できます。

準備ができたら「ハック」を押して、試練を完了しましょう。
