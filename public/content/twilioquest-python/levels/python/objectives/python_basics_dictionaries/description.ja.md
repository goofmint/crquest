`super_hero` という名前の[辞書](https://docs.python.org/3/library/stdtypes.html#mapping-types-dict)を作り、次の項目を設定します。キーと文字列の値は表のとおりに入力してください。

| キー | 値 | 値の型 |
| --- | --- | --- |
| name | `Miles Morales` | 文字列 |
| hero_name | `Spider-Man` | 文字列 |
| power_level | `9999` | 整数 |

`dictionaries.py` でこれらの項目を含む `super_hero` を作りましょう。

準備ができたら「ハック」を押して、試練を完了しましょう。
