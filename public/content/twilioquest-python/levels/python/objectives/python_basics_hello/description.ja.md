# あいさつの試練

パソコン上のフォルダーに `salutation.py` という Python ファイルを作りましょう。このフォルダーは今後の試練でも使います。`salutation.py` に次のコードを書き、伝統のあいさつをターミナルに表示します。

```python
# Your first line of Python code is below!
print("For the glory of Python!")
```

先ほどインストールした `python3` コマンドで実行しましょう。

```bash
python3 salutation.py
```

Windows で Python 3 の実行ファイルが `python.exe` の場合は、次のように実行します。

```powershell
python salutation.py
```

英語のあいさつが正しく表示されたら、**コードのフルパスを右の入力欄に貼り付けて**ください。コードを検証し、フォルダーの場所を今後の試練のために保存します。

準備ができたら「ハック」を押して、試練を完了しましょう。
