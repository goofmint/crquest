コードが扱うデータを表す[変数](https://www.w3schools.com/python/python_variables.asp)を作ります。コード用フォルダーの `variables.py` に次の変数を定義してください。

* `favorite_robot` の値は `"Cedric"`
* `meaning_of_life` の値は `42`

名前と値は記載どおりに入力してください。

準備ができたら「ハック」を押して、試練を完了しましょう。
