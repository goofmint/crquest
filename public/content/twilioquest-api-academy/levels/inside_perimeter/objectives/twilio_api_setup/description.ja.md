# 真実の像を通り抜ける

地下墓地のような Twilio API を使うプログラミング課題には、Twilio アカウントが必要です。[Twilio アカウントを作成](https://www.twilio.com/try-twilio?utm_source=twilioquest-3) し、API の認証情報である **Account SID** と **Auth Token** を確認してください。認証情報は [Console のホーム画面](https://www.twilio.com/console) で確認できます。

右側の入力欄に両方の値をそのまま入力し、*HACK* を押してください。認証情報は形式だけを検証します。Account SID は `AC` に続く 32 桁の 16 進数、Auth Token は 32 桁の 16 進数です。今後の Twilio 関連の課題で使うため TwilioQuest が保存します。この検証では Twilio に送信されません。
