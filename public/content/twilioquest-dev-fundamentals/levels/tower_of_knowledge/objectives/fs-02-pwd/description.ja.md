ファイルパスが分かったところで、いま作業している場所をターミナルで確認してみましょう。

`<%= isWindows ? "PowerShell" : "Terminal" %>` を開いてください。ほとんど何も表示されていない画面で、カーソルが点滅しています。これがターミナルです。

ターミナルは開発に役立つ強力な道具です。最初のうちは戸惑うかもしれませんが、コマンドを一つずつ試していきましょう。

> 💡 ターミナルの仕組みは **無限知識の塔** の別の階でさらに学べます。この階では、ターミナルの基本操作を知っているものとして進みます。

Spotify や Chrome などの多くのアプリは、マウスでボタンや画像をクリックして操作する **グラフィカルインターフェース** を備えています。ターミナルはコマンドを入力して操作する **テキストインターフェース** です。

ターミナルで作業するときは、常にどこかのディレクトリにいます。ディレクトリの移動方法を学ぶ前に、自分がいまどこにいるかを確かめましょう。

ターミナルに `pwd` と入力してください。表示されたパスをそのまま右側の入力欄に貼り付け、_HACK_ を押します。
