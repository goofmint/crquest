# 作業ディレクトリ

グラフィカルインターフェースに慣れていると、「作業ディレクトリ」は聞き慣れないかもしれません。グラフィカル環境では、アプリを開けるデスクトップを作業の起点にすることが多く、ディレクトリを意識するのはファイルやフォルダーを開くときくらいです。

ターミナルでは、デスクトップもファイルを置けるディレクトリの一つです。ターミナルを開いた直後は通常、そのコンピューター上のユーザーアカウントに割り当てられた「ホームディレクトリ」にいます。

ターミナルでコマンドを実行するのは、デスクトップでアプリを起動するのと似ています。メニューやツールバーのアイコンをクリックする代わりに、コマンドを入力してプログラムを起動します。

起動されたディレクトリを利用するプログラムもあります。例えば、相対パスを使ってファイルを探す場合です。ファイルを作成・削除するコマンドでは特に重要です。このディレクトリをプログラムの「作業ディレクトリ」と呼びます。通常は、ターミナルでコマンドを実行した時点のディレクトリです。

`pwd` は、いまターミナルで開いている作業ディレクトリを表示します。JavaScript テストラボや Python の神殿では、コードを置くディレクトリのパスを入力することになります。`pwd` でそのパスを簡単に取得でき、作業場所を見失ったときにも確認できます。

## `pwd` はなぜ必要？

ターミナルがコマンドの入力欄の前にディレクトリを表示しているなら、なぜ `pwd` が必要なのでしょうか。

その行は「プロンプト」と呼ばれ、コマンドなどの新しい入力を受け付けられることを知らせます。プロンプトにはさまざまな情報を表示でき、初期設定では `pwd` と同じように現在の作業ディレクトリが表示されることもよくあります。

コーディングやターミナルに慣れてきたら、プロンプトに別の情報を表示したり、情報を一切表示しない簡素な設定にしたりできます。必要なときに作業ディレクトリの完全なパスを調べる方法を覚えておくと便利です。

スクリプトでも便利です。テキストインターフェースではコマンドを組み合わせ、複雑な手順を小さなプログラムにまとめられます。作業ディレクトリを別のコマンドに渡す処理を自動化するときに `pwd` が役立ちます。
