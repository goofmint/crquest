# 隠しファイル

隠しファイルは、グラフィカルなファイル管理アプリや、`ls` などのコマンドで一覧を表示しても通常は見えないファイルです。

隠しファイルには、利用頻度の低いデータがよく保存されます。OS やアプリが必要とするデータのうち、利用者が直接編集する必要のないものなどです。アプリの設定は隠しファイルに保存される場合があり、その場合はテキストエディターで直接開くのではなく、アプリの設定メニューで変更します。

自分で隠しファイルを作る場合もあります。`.gitignore` がその一例です。プロジェクト内で、バージョン管理システムの `git` に無視してほしいファイルを指定します。作成後に直接使わないことが多いので、隠しファイルになっています。

隠しファイルの名前は `.` で始まることがよくあります。Linux や Unix 系の OS では先頭に `.` が付いたファイルやフォルダーは隠し項目として扱われます。Windows では `hidden` 属性を設定する必要があります。Windows が作る隠しファイルは通常 `.` で始まりませんが、Unix 系 OS の慣習として `.` が使われているため、Windows でも先頭に `.` が付くファイルやフォルダーを見かけることがあります。

<% if(isWindows) { %>
Windows では属性を変更してファイルを隠します。PowerShell で属性を設定するコマンドは `attrib` です。ファイルを隠すには `attrib +h` を使います。隠しファイルを作りたい場合は、`ni yourhiddenfilename.txt` でファイルを作成し、`attrib +h yourhiddenfilename.txt` で属性を変更します。
<% } else { %>
Linux や macOS ではファイル名の先頭を `.` にすると隠しファイルになります。例えば `.gitignore` です。`touch .yourhiddenfile.txt` なら 1 回のコマンドで作成できます。既存ファイルを隠すには `mv` で名前を変更します。`mv` は名前の変更やファイルの移動に使うコマンドです。`mv` には元のファイル名と新しい名前を渡します。例えば `mv notahiddenfile.txt .nowahiddenfile.txt` を実行すると、`notahiddenfile.txt` は `.nowahiddenfile.txt` となり、先頭に `.` が付いて隠しファイルになります。

<% } %>

# 隠しファイルの表示

隠しファイルは通常表示されませんが、グラフィカルなファイル管理アプリやコマンドラインで表示できます。

<% if(isWindows) { %>

PowerShell では `dir -ah` で隠しファイルを表示できます。`-ah` は「Attributes: Hidden（隠し属性）」を意味し、隠し属性を持つファイルを表示するフラグです。

## PowerShell のエイリアスとオプション

以前、PowerShell でファイル一覧を表示するときに `ls` を使いました。PowerShell の `ls` は別名です。Unix の一覧表示コマンド `ls` に慣れた人が使えるよう、PowerShell は `dir` の別名として提供しています。`ls` で隠しファイルを表示する方法を探すと、`ls -a` が見つかるかもしれません。このコマンドは PowerShell ではエラーになります。`ls` は `dir` の別名で、`dir` と Unix の `ls` は引数やオプションが異なります。`ls` のエイリアスは、オプションまでは変換しません。

Unix の `ls` では `-a` フラグで先頭が `.` のファイルを表示します。PowerShell の `-a` は単独では無効です。属性を絞り込むフラグなので、属性を表す文字を後ろに続ける必要があります。`-ah` の `h` は隠し属性を表します。
<% } else { %>
Linux や macOS では `ls -a` で隠しファイルを表示します。`-a` を付けると、名前が `.` で始まるファイルやフォルダーも一覧に含まれます。
<% } %>
