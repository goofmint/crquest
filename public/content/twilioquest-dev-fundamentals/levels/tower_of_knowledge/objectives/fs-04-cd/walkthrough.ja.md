# ディレクトリの変更

`cd` で移動するいちばん簡単な方法は、現在の作業ディレクトリ内にあるディレクトリの名前を指定することです。`ls` と組み合わせると便利です。`ls` で移動先を確認し、`cd` で移動できます。

これも相対パスの例です。`cd` は現在の作業ディレクトリを起点とするため、`cd` に完全なパス（絶対パス）を渡す必要はありません。

`cd` に長いパスを渡すと、移動の手間を省けます。`ls` で一覧を見て `cd` で移動し、もう一度 `ls` で一覧を見て `cd` で移動する代わりに、`cd` に移動先のパスをまとめて指定できます。

```
$ cd <%= `${formatPathPartsForOs('cedric', 'robot_thoughts')}`%>
```

これで複数のディレクトリを一度に移動できます。ルートから始まる絶対パスを渡せば、現在のディレクトリの外にある場所にも移動できます。

## 親ディレクトリに戻る

`ls` には現在のディレクトリの内容が表示されます。一つ上にある親ディレクトリへ `cd` で戻るにはどうすればよいでしょうか。

親ディレクトリは `..` で表します。親ディレクトリに戻るには `cd ..` を使います。`ls` にも使えるので、`ls ..` で親ディレクトリの中身を確認できます。これらをパスとしてつなぐと、一度に何階層も戻れます。`cd <%= `${formatPathPartsForOs('..', '..')}`%>` は二つ上、`cd <%= `${formatPathPartsForOs('..', '..', '..')}`%>` は三つ上に移動します。

`..` は親ディレクトリ、`.` は現在のディレクトリを指します。`cd .` を実行すると、作業ディレクトリはそのままです。

## ホームディレクトリに戻る

ターミナルを開いたときにいたホームディレクトリは `~` で指定できます。戻るには `cd ~` を使います。`ls` とも組み合わせられ、`ls ~` でホームディレクトリの中身を表示できます。
