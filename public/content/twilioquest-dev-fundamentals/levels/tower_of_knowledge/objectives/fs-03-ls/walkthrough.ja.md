# ディレクトリの中身を表示する

`ls` は現在のディレクトリにあるファイルとディレクトリを一覧表示します。ターミナルで `ls` を実行し、表示されたファイルかディレクトリの名前を一つ入力してください。

<% if(isWindows) { %>

`ls` の一覧では、ファイルとディレクトリがすぐに見分けられないことがあります。`ls` にフラグを渡すと、表示する種類を絞れます。フラグは `-` で始まるオプションです。ディレクトリだけなら `ls -Directory`、ファイルだけなら `ls -File` を使います。

> ⚠️ PowerShell の `ls` は `Get-ChildItem` の別名です。Linux や Mac では `ls` は独立したコマンドです。そちらの `ls` と PowerShell の `ls` では動作が異なります。PowerShell の `ls` が実際には `Get-ChildItem` を呼ぶためです。OS を切り替えるときは覚えておきましょう。

<% } else { %>

`ls` は名前のほか、サイズ、ファイルの読み書き権限、最終更新日時なども表示できます。こうした情報を出すには `ls` にフラグを渡します。フラグは `-` で始まるオプションです。例えば、ファイルとディレクトリを見分けたいときは `ls -F` を使います。`-F` は種類を識別するためのフラグで、`ls` の出力がファイルかディレクトリか分かるように印を付けます。

ファイル名を入力するときは、末尾に表示された種類を示す記号（実行可能ファイルに付く * など）を除き、実際の名前だけを入力してください。

<% } %>
