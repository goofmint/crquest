# ファイルやディレクトリを見つける

<div class="aside">
<h3>達成条件</h3>
<ul>
  <li>ターミナルを開きます。</li>
  <li><b>ls</b> コマンドを入力します。</li>
  <li>表示されたファイルかディレクトリの名前を一つ選び、右側の入力欄に貼り付けます。</li>

ホームディレクトリの場所が分かったので、次はそこに何があるかを調べます。

<% if(isWindows) { %>

二つ目のコマンドは `ls` です。名前は **list** に由来し、ディレクトリの中身を一覧表示します。

実行すると、前の課題で学んだ「現在の作業ディレクトリ」に含まれるファイルとディレクトリの名前が並びます。

ターミナルに `ls` と入力してください。表示された名前を一つ選んで、そのまま右側の入力欄に貼り付け、_HACK_ を押します。

<% } else { %>
