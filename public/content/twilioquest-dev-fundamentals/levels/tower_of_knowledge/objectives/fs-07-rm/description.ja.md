# ファイルを削除する

<div class="aside">
<h3>達成条件</h3>
<ul>
  <li><b>rm</b> でファイルを削除します。</li>
  <li>削除したら <em>HACK</em> を押します。</li>
</ul>
</div>

ファイルを作れるようになったので、次は削除する方法を学びましょう。

前の課題で作ったファイルを `rm`（remove、削除）で消します。ターミナルで `rm` に続けて、削除するファイルへのパスを入力してください。

次は「l33tcode.txt」を削除する例です。削除の前後で `ls` を実行し、ファイルが消えたことを確認します。

```bash
$ ls
l33tcode.txt

$ rm l33tcode.txt

$ ls
*should not show anything*
```

前の課題で作ったファイルを `rm` で削除してください。ファイルがなくなったら、_HACK_ を押します。
