炉のこの区画では、未加工のダークダックティピウムにさらされたことで生じたソフトウェアのバグを修理しているようです。このプログラムは、貯蔵槽の診断情報を生成するためのものです。

## findLongestDiagnosticUrl 関数

`findLongestDiagnosticUrl` 関数は貯蔵槽を表すオブジェクトの配列を取ります。各オブジェクトには、槽の状態を表すメタデータが入っています。

各槽には[対応する診断 URL](https://www.twilio.com/quest/ducktypium-diagnostics)があります。正しい情報を表示できるよう、槽のメタデータは URL のクエリパラメーターに入っています。

この関数では、渡された診断 URL の一覧から最も長いものを返してください。

関数のバグを修正したら、_ハック_ ボタンをクリックしてください！
