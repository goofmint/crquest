# 文の単語を逆順に

<div class="aside">
<h3>要件</h3>
<ul>
  <li>`reverseSentence` という名前の関数を作成します。</li>
  <li>この関数は、大文字で始まり句読点で終わる英文の文字列を受け取ります。</li>
  <li>文に次の処理を行った新しい文字列を返します。</li>
  <ul>
    <li>元の文の最初の単語を小文字にします。</li>
    <li>単語の順序を逆にします。</li>
    <li>新しい文の最初の単語の頭文字を大文字にします。</li>
    <li>ほかの単語の大文字・小文字は変更しません。</li>
    <li>句読点は文末に残します。</li>
  </ul>
  <li>終わったら <em>ハック</em> を押します。</li>
</ul>
</div>

炉のこの区画では計算を行っているようです。この端末では、ダークダックティピウムが人間の話し方に与える影響を調べています。

文字列を第1引数に取る関数 `reverseSentence` を作成してください。入力の英文に次の処理を行います。

- 元の文の最初の単語を小文字にする
- 単語の順序を逆にする
- 新しい文の最初の単語の頭文字を大文字にする
- ほかの単語の大文字・小文字は変更しない
- 句読点は文末に残す

## 例

- `Happy New Year!` -> `Year New happy!`
- `Elephants are big!` -> `Big are elephants!`
- `My cat Pierogi is hungry.` -> `Hungry is Pierogi cat my.`

関数を書いたら、_ハック_ ボタンをクリックしてください！
