炉のこの区画では、未加工のダークダックティピウムにさらされたことで生じたソフトウェアのバグを修理しているようです。このプログラムは、ダークダックティピウムの貯蔵槽が満杯になったことを検知するためのものです。

## monitorReservoirs 関数

`monitorReservoirs` 関数は貯蔵槽を表すオブジェクトの配列を取ります。各オブジェクトには、槽の状態を表すメタデータが入っています。

この関数で重要なプロパティは `contents` と `type` です。

- `contents` は槽に入っているダックティピウムの量を表す数値です。
- `type` は槽に入っているダックティピウムの種類を表す文字列です。

この関数では、`type` が `"raw"` であり、`contents` にダックティピウムが100以上ある槽だけを配列で返してください。

関数のバグを修正したら、_ハック_ ボタンをクリックしてください！
