# 配列に含まれる数値の合計

<div class="aside">
<h3>要件</h3>
<ul>
  <li>`sumArray` という名前の関数を作成します。</li>
  <li>この関数は数値の配列を受け取ります。</li>
  <li>配列が空の場合、合計は `0` です。</li>
  <li>配列内のすべての数値を加算し、合計を返します。</li>
  <li>終わったら <em>ハック</em> を押します。</li>
</ul>
</div>

炉のこの区画では計算を行っているようです。この端末では、生産されたダークダックティピウムの総質量を計算しています。

数値の配列を第1引数に取る関数 `sumArray` を作成してください。すべての数値を足し合わせて合計を返します。

<br>

## 例

- `[1, 2, 3]` -> `6`
- `[-1, 0, 1]` -> `0`
- `[2.5, 5]` -> `7.5`
- `[]` -> `0`

<br>

関数を書いたら、_ハック_ ボタンをクリックしてください！
