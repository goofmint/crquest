# 重複する文字を削除

<div class="aside">
<h3>要件</h3>
<ul>
  <li>`removeDuplicateCharacters` という名前の関数を作成します。</li>
  <li>この関数は文字列を受け取ります。</li>
  <li>同じ文字の連続をすべて1文字にまとめた新しい文字列を返します。</li>
  <li>終わったら <em>ハック</em> を押します。</li>
</ul>
</div>

炉のこの区画では計算を行っているようです。この端末は、ダックティピウムを黒くする手順の命令列に連続する重複がないようにするためのものです。

文字列を第1引数に取る関数 `removeDuplicateCharacters` を作成してください。同じ文字が連続する箇所は、すべて1文字にまとめます。

## 例

- `aabbcc` -> `abc`
- `xyyx` -> `xyx`
- `aaaaaaaaaaaaaaabc` -> `abc`

関数を書いたら、_ハック_ ボタンをクリックしてください！
