# 回文を判定

<div class="aside">
<h3>要件</h3>
<ul>
  <li>`isPalindrome` という名前の関数を作成します。</li>
  <li>この関数は文字列を受け取ります。</li>
  <li>前から読んでも後ろから読んでも同じになる回文なら true、そうでなければ false を返します。</li>
  <li>入力文字列が空、または1文字だけなら、true を返します。</li>
  <li>終わったら <em>ハック</em> を押します。</li>
</ul>
</div>

炉のこの区画は電力を生成し、残りのシステムに供給しているようです。この端末は、システムを通過する信号を安定させ、純粋な回文エネルギーを炉に送り続けるためのものです。

文字列を受け取る関数 `isPalindrome` を作成してください。前から読んでも後ろから読んでも同じかどうかを、真偽値（true/false）で返します。判定前に、入力文字列に次の処理を行います。

- 文字列を小文字に変換する
- 空白を削除する

<br>

詳しくは[回文についての Wikipedia の記事](https://en.wikipedia.org/wiki/Palindrome)を参照してください。

## 例

- `tacocat` -> `true`
- `""` -> `true`
- `heLLo` -> `false`
- `Never odd or even` -> `true`

<br>

関数を書いたら、_ハック_ ボタンをクリックしてください！
