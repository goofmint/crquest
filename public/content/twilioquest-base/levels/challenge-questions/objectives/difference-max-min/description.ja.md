# 最大値と最小値の差

<div class="aside">
<h3>要件</h3>
<ul>
  <li>`differenceMinMax` という名前の関数を作成します。</li>
  <li>この関数は数値の配列を受け取ります。</li>
  <li>配列に含まれる最大の数と最小の数の差を返します。</li>
  <li>終わったら <em>ハック</em> を押します。</li>
</ul>
</div>

炉のこの区画では計算を行っているようです。この端末では、ダックティピウムを黒くするのに適した温度範囲を求めています。

数値の配列を第1引数に取る関数 `differenceMinMax` を作成してください。この関数は、配列内の最大値と最小値の差（引き算の結果）を返します。書けたら _ハック_ ボタンをクリックしてください。
