# 罠のある壺

<div class="aside">
<h3>要件</h3>
<ul>
  <li>セドリックが割るべき壺の種類を考えます。</li>
  <li>右側の入力欄に、壺の色を `white and green`、`terracotta`、`gray` のいずれかで入力します。</li>
  <li>終わったら <em>ハック</em> を押します。</li>
</ul>
</div>

セドリックは、ほかに何もない廊下に散らばった壺を見つけました。O.W.L. ユニットがまた、どれかの壺に調べる価値のある物が入っていると示しています。ただし、ほかの壺には罠があるとの警告も出ています。

![白と緑の壺が3個、テラコッタ色の壺が2個、灰色の壺が1個並ぶ廊下](<%= imagePath %>)

O.W.L. ユニットは壺について、さまざまな情報を集めました。どの色の壺を割ればよいか、セドリックに教えてあげましょう。

- 壺は `white and green`、`terracotta`、`gray` の3色です。
- 最も数が多い壺は、作られてから100年以内です。
- 最も数が少ない壺は、塗装が剥げ始めています。
- テラコッタ色の壺は、年月が経ってひび割れています。
- 最も新しい壺には罠があります。
- 塗装が剥げている壺は、作られてから200〜300年経過しています。
- ひび割れた壺は、作られてから少なくとも500年経過しています。
- 最も古い壺にも罠があります。

セドリックが割れるように罠のない壺の色を英語で入力し、_ハック_ ボタンをクリックしてください！
