# 括弧の対応を確認

<div class="aside">
<h3>要件</h3>
<ul>
  <li>`balanceBrackets` という名前の関数を作成します。</li>
  <li>この関数は括弧の配列を受け取ります。括弧は "[", "]", "(", ")", "{", "}" のいずれかです。</li>
  <li>括弧が対応しているなら true、そうでなければ false を返します。下の例を参考にしてください。</li>
  <li>入力配列が空の場合は true を返します。</li>
  <li>終わったら <em>ハック</em> を押します。</li>
</ul>
</div>

炉のこの区画は電力を生成し、残りのシステムに供給しているようです。この端末は、発電機の燃料の混合比を適切に保つためのものです。

括弧の配列を引数に取る関数 `balanceBrackets` を作成してください。配列内の括弧が対応しているかどうかを、真偽値（true/false）で返します。

<br>

## 例

- `["{", "}"]` -> `true`
- `["[", "(", "]", ")"]` -> `false`
- `[]` -> `true`
- `["{", "[", "}"]` -> `false`
- `["]", "(", ")", "["]` -> `false`
- `["(", ")", "[", "(", "{", "}", ")", "]"]` -> `true`

<br>

関数を書いたら、_ハック_ ボタンをクリックしてください！
