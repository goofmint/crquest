# セドリックを神殿へ案内しよう

<div class="aside">
<h3>要件</h3>
<ul>
  <li>上、下、左、右の移動指示を英語で入力して、セドリックを神殿の入り口まで案内します。</li>
  <li>終わったら <em>ハック</em> を押します。</li>
</ul>
</div>

セドリックはダークダックティピウムの兜を探していますが、光学センサーが停止してしまいました。神殿の扉までの道順を教えてあげましょう。

セドリックを案内するには、移動指示の一覧を作ります。指定できるのは `up`、`down`、`left`、`right` です。どの指示も、その方向に1マス移動するという意味です。

たとえば、右に1回進んでから下に2回進むよう指示するには、文字列 `right down down` を入力します。`up down left right` ならセドリックは出発した場所に戻ります。
