# 配列を平坦化

<div class="aside">
<h3>要件</h3>
<ul>
  <li>`flattenArray` という名前の関数を作成します。</li>
  <li>この関数は配列を受け取ります。配列には、数値、文字列、オブジェクト、ほかの配列が入っていることがあります。</li>
  <li>入力を平坦化し、すべての要素を含む新しい配列を返します。</li>
  <li>入力配列が空の場合は、英語の文字列 "Pure Ducktypium!" を返します。</li>
  <li>終わったら <em>ハック</em> を押します。</li>
</ul>
</div>

炉のこの区画は電力を生成し、残りのシステムに供給しているようです。この端末はダークダックティピウムの不純物を取り除くためのものです。

さまざまな型の要素を含められる配列を受け取る関数 `flattenArray` を作成してください。どれだけ深く入れ子になっていても、すべての要素を取り出した新しい平坦な配列を返します。空の配列の場合は、英語の文字列 `Pure Ducktypium!` を返します。

<br>

## 例

- `[]` -> `Pure Ducktypium!`
- `[1, "two", 3, "four"]` -> `[1, "two", 3, "four"]`
- `[1, 3, 3, 7, ["legacy wuz here"]]` -> `[1, 3, 3, 7, "legacy wuz here"]`
- `["python", ["javascript", ["api", ["messaging"]]]]` -> `["python", "javascript", "api", "messaging"]`

<br>

関数を書いたら、_ハック_ ボタンをクリックしてください！
