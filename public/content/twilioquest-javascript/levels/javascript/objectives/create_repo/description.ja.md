# Git で作業の履歴を残そう

<div class="aside">
<h3>やること</h3>
<ul>
  <li>コード用フォルダーで Git リポジトリを初期化する。</li>
  <li>作業用フォルダーの現在の内容をコミットする。</li>
</ul>
</div>

**オープンソースの炎**で補給用の宝箱を覆う茂みを燃やしました。宝箱には鍵がかかっていますが、Git の知識を示せば開けられそうです。

このミッションで使ってきた JavaScript のコード用フォルダーに移動してください。場所は次のとおりです。

`<%= env.TQ_JAVASCRIPT_WORKSPACE_PATH.value %>`

そこで新しいリポジトリを初期化し、現在の内容をコミットします。

```bash
git init
git add -A
git commit -m "Initial Commit"
```

この手順で Git リポジトリを初期化し、サンプルファイルをすべて追加して、メッセージを付けてコミットできます。完了したら、*ハック*をクリックして確認してください。
