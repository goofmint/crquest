貨物船 **Infinite Loop** のセキュリティで守られた貨物室で、TwilioQuest プログラムの電気技師にたどり着くために解除すべきセキュリティノードを発見しました。

ノードは、**二次元配列**に格納された 2 つの環境変数の設定が誤っているため、ロックされています。

変数に正しい値を設定し、ノードをハックして、**Infinite Loop** のマスターパスワードに必要なインデックスを入手してください。

## 二次元配列を理解する

次の[二次元配列](https://medium.com/javascript-in-plain-english/javascript-multi-dimensional-arrays-7186e8edd03)を見てみましょう。

```js
const twoDimensionalArray = [
  ['dogs', 'cats', 'zebras'],
  ['pizza', 'tacos', 'kale'],
  ['baseball', 'football', 'hockey']
];
```

右側の入力欄では、異なる 2 つのインデックスでの値を聞かれます。値が分かったら英語のまま対応する欄に入力し、*ハック*をクリックしてください。
