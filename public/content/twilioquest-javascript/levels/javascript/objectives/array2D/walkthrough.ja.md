# パスワードのインデックスを見つける

この最後の課題では、二次元配列のデータにアクセスする方法を学びます。二次元配列は、格子上の点やチェス盤の駒など、二次元空間の情報を表すためによく使われます。

通常の配列と同様に、**添字記法**でデータを参照します。

一次元配列には添字がひとつだけあります。次の配列を見てみましょう。

```js
const animals = ['dog', 'cat', 'bird'];
```

`cat` は 2 番目の要素、`animals[1]` にあります。

二次元配列では、文字列や数値の代わりに、配列の中に配列が入っています。次の配列は、線上の点の X/Y 座標として考えることができます。

```js
const points = [ [0,1], [1,2], [2,3] ];
```

`points` のインデックス 0 にある値は、別の配列 `[0,1]` です。つまり `points[0]` は `[0,1]` と等しく、`points[0]` は配列なのでその値にも添字でアクセスできます。この例では、`points[0][1]` は `1` です。`points` 内の配列の 2 番目の要素だからです。

最初の数値を二次元配列の「行」、次の数値を「列」と考えると分かりやすくなります。次のように整形すると見やすくなります。整形によって値は変わりません。

```js
const points = [ 
  [0, 1], 
  [1, 2], 
  [2, 3] 
];
```

二次元配列の参照方法が分かったら、右の質問に答え、*ハック*をクリックしてください。使うのは上の例ではなく、目標タブにある二次元配列です。
