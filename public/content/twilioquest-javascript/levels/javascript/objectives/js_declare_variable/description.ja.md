# セキュリティ設定の上書き

<div class="aside">
<h3>やること</h3>
<ul>
  <li><code>laserConfiguration.js</code> を作成する。</li>
  <li><code>laserStatus</code> 変数を宣言し、文字列 "OFF" を設定する。</li>
  <li>できたら<em>ハック</em>をクリックする。</li>
</ul>
</div>

主任研究員のオフィスへの行く手を、別の障壁がふさいでいます。調べると、レーザーの柵が「ON」に固定されるよう JavaScript で設定されています。障壁を解除するには、**自分の JavaScript コードで設定を上書き**しましょう。

コード用フォルダーに `laserConfiguration.js` を作ります。中に `laserStatus` という[変数](https://en.wikipedia.org/wiki/Variable_(computer_science))を宣言し、[文字列](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String)の値 `OFF` を英語のまま設定してください。

できたら *ハック* をクリックし、コードを確認してこの障壁のレーザー設定を上書きします。
