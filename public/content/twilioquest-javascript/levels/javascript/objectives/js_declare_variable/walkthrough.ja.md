# JavaScript で変数を作る

この練習の目的は、JavaScript コードで[変数を作成](https://javascript.info/variables)することです。変数には、テキストや数値など、プログラムが扱うデータを入れられます。変数名を使えば、コードから名前でデータを参照できます。

次のコード用フォルダーに `laserConfiguration.js` を作成してください。

`<%= env.TQ_JAVASCRIPT_WORKSPACE_PATH.value %>`

そのファイル内で、目標で指定された名前と値の変数を宣言します。以下は、別の名前と値で変数を作成する例です。ひな型として使えますが、そのままでは検証を通りません。

```js
const favoriteRobot = 'Cedric';
console.log('My favorite robot is ' + favoriteRobot);
```

目標タブの指示に従って変数を宣言したら、*ハック*をクリックしてください。
