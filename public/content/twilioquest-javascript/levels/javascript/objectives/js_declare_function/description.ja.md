# 関数を作ろう

<div class="aside">
<h3>やること</h3>
<ul>
  <li><code>laserFunction.js</code> を作成する。</li>
  <li>文字列 "OFF" を返す <code>getLaserSetting</code> 関数を作る。</li>
  <li>できたら<em>ハック</em>をクリックする。</li>
</ul>
</div>

事故で荒れた施設の中に、研究区画への進入を防ぐ新たな障壁が見つかりました。

この障壁を調べると、レーザーが `"ON"` か `"OFF"` かは **JavaScript 関数**で決まると分かりました。障壁を解除するため、この**関数を書き換えましょう**。

コード用フォルダーで `laserFunction.js` を作成します。その中に `getLaserSetting` という[JavaScript 関数を作成](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Functions)してください。[文字列](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String)の `"OFF"` を英語のまま**返す**関数です。

準備できたら、*ハック*をクリックしてレーザー制御関数を書き換えましょう。
