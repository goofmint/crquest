# Node.js をインストールする

ラボに入る前にセキュリティチェックを受けます。コンピューターのターミナルで **JavaScript プログラムを実行**するために必要なソフトウェアがインストールされていることを示してください。

[Node.js の最新版をダウンロードし、インストール](https://www.nodejs.org)してください。インストール後は、PowerShell やターミナルなどで `node` コマンドを使えるようになります。

右の入力欄に、あなたのコンピューターにインストールされた `node` コマンドの**フルパス**を貼り付け、*ハック*をクリックしてください。パスの調べ方が分からない場合はヘルプタブを確認してください。
