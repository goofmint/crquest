# 植物に水をやろう

<div class="aside">
<h3>やること</h3>
<ul>
  <li><code>shouldWater.js</code> を作成する。</li>
  <li>数値を 2 つ、コマンドライン引数で取得する。最初が木の状態 ID、次が乾燥度。</li>
  <li>最初の引数が <code>0</code> で、2 番目の引数が <code>10</code> より大きければ、<code>WATER</code> を出力する。</li>

植物学ラボの南東の隅で、ダックタイピウムの事故で故障した別の装置が見つかりました。自動スプリンクラーが止まり、その影響で**南の橋も無効になった**ようです。

植物に水をやり、南の橋を延ばすために、自動スプリンクラーを修理しましょう。

## 雨を降らせる

スプリンクラーを調べると、ブール論理に不具合があります。修理するため、コード用フォルダーに `shouldWater.js` を作成します。スクリプトは**コマンドライン引数を 2 つ**受け取り、どちらも数値です。

* 最初は植物の状態で、`0` は生きていることを示す。
* 2 番目は植物の乾燥度で、`10` より大きい場合は水が必要。

生きている植物（状態 `0`）で乾燥度 `20` の場合の実行例です。

```bash
node shouldWater.js 0 20
```

スプリンクラーを正しく動かすには、英語で `WATER` と出力します。ただし、1 番目の引数が `0` かつ 2 番目が `10` より大きい場合に限ります。それ以外では何も出力しません。

仕様どおりに動いたら、*ハック*をクリックしてスプリンクラーを直しましょう！
