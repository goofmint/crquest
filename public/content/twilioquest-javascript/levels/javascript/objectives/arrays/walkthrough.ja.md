# 目標のヘルプ

このエリアの課題ではすべて、[配列](https://javascript.info/array)を使います。配列は、順番のある要素のリストです。詳しくは[MDN の配列リファレンス](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array)を確認してください。

目標を達成するには、次のコード用フォルダーに `freighterInventory.js` を作成します。

`<%= env.TQ_JAVASCRIPT_WORKSPACE_PATH.value %>`

`freighterInventory.js` では、指示に従って配列変数 `inventory` を宣言します。目標タブにある 5 つの文字列を、英語のまま掲載順に格納してください。用意ができたら、*ハック*をクリックして確認しましょう。
