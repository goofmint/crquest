ラボの東棟に入ると、貨物船のためのエアロックがありました。爆発で、**研究チームの技師**が補給船に閉じ込められたようです！

最近の積荷目録を調べると、現在ドッキングしている貨物船は **Infinite Loop** という名前でした。各システムは、要素のリストである[配列](https://javascript.info/array)を使う JavaScript で制御されています。行く手を阻む制御装置を通過するには、配列をさまざまに使う JavaScript コードを書く必要があります。

## 積荷を確認する

**Infinite Loop** の貨物一覧が誤って消去され、このレーザー障壁が作動しました。修復して先に進みましょう。

コード用フォルダーに `freighterInventory.js` を作成し、そのファイル内で `inventory` を宣言してください。変数には、次の 5 つの[文字列](https://javascript.info/string)を英語のまま、示された順に入れた配列を格納してください。

- `"Ducktypium Ore"`
- `"Uranium Rod"`
- `"Ruthenium Isotopes"`
- `"Concave Lens"`
- `"Refraction Panel"`

以上の要素を含む `inventory` を作成したら、*ハック*をクリックしてください。
