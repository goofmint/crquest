# 変数をもう少し練習する

[変数を作る練習](https://javascript.info/variables)をもう少し続けましょう！

今回はよく使う [JavaScript のデータ型](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Data_structures)で、**3 つの変数を宣言**します。ラボの奥へ進むにつれて、これらのデータ型をさらに学びます。

次のコード用フォルダーに `chestConfiguration.js` を作成してください。

`<%= env.TQ_JAVASCRIPT_WORKSPACE_PATH.value %>`

そこで、目標にある名前と値で 3 つの変数を宣言してください。次のコードをひな型にできますが、名前と値を変更する必要があります。

```js
const mulletLooksGood = false;
const meaningOfLife = 42;
const bestCharacter = 'Baby Yoda';

console.log('Mullets look good? ' + mulletLooksGood);
console.log('The meaning of life is: ' + meaningOfLife);
console.log('My favorite character in Star Wars is: ' + bestCharacter);
```

目標タブの指示どおりに宣言したら、*ハック*をクリックしてください。
