ラボの北棟の中央に、用途の分からない装置があります。手前のコンソールを調べて、これが**物質実体化装置**の操作パネルだと分かりました。部屋の真ん中にある大きなチャンバーのことですね！

ところがコンソールはエラーログで埋まり、ラボの爆発で損傷したようです。このコンソールと同型のもう一台を復旧できれば、中央の装置も再び動くはずです。

## クラスでコンソールを修理

物質実体化装置の部品を直すには、変換処理が使う設定オブジェクトを提供する JavaScript コードを書き換える必要があります。

コード用フォルダーに `classes.js` を作り、`Materializer` という[クラスを定義](https://javascript.info/class)してください。

次の仕様を満たすようにします。

- コンストラクターの最初の引数を `target` プロパティに設定する。
- `activated` プロパティの初期値は `false` とする。
- `activate` インスタンスメソッドで `activated` を true にする。
- `materialize` インスタンスメソッドは、インスタンスの `target` の値を返すのは、`activated` が true の場合。それ以外なら `undefined` を返す（値を返さない）。

仕様を満たす `Materializer` クラスができたら、*ハック*をクリックして確認しましょう。
