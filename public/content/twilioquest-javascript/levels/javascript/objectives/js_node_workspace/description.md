# Create a Workspace

Several activities inside the lab will require that you create JavaScript code files on your computer. The next screening checkpoint is set up to confirm that you have a folder on your computer's file system where you can keep all of these files. 

**Create a folder** on your computer to keep your JavaScript code. Once you have done so, click **Choose Folder** on the right and select your folder (the full path appears in the field), then click the *HACK* button.

The game can only look inside a folder you picked with **Choose Folder**. A path that is only pasted into the field may be rejected with a permission message; if so, choose the folder again with the button.
