障壁を調べると、JavaScript ラボの IT 部門にしか解除できません。IT に連絡するとグレンという技術者につながりました。彼は渋々ながら、丁寧に頼むなら障壁を解除すると約束します。

先へ進むには、グレンに障壁を開けてもらうよう丁寧にお願いする **JavaScript プログラム**を書きます。前に作ったフォルダーに `sayPlease.js` という JavaScript ファイルを作成してください。フォルダーの場所は次のとおりです。

`<%= env.TQ_JAVASCRIPT_WORKSPACE_PATH.value %>`

`sayPlease.js` に次の JavaScript コードをそのまま貼り付けます。

```js
console.log('Glen, will you please open the barrier?');
```

丁寧な依頼が出力されることを確認したら、*ハック*をクリックしてください。グレンが応じてくれるといいですね。
