# スクリプトの引数

<div class="aside">
<h3>やること</h3>
<ul>
  <li><code>divideByTwo.js</code> というファイルを作成する。</li>
  <li>コマンドライン引数で渡された文字列を数値に変換する。</li>
  <li>その数値を 2 で割る。</li>
  <li><code>console.log</code> で結果を出力する。</li>
</ul>
</div>

障壁の向こう、主任研究員の机の上には紙の束があります。探しているパスワードはそこにあるはず。ダックタイピウムの実験を続けるための情報まで、あと少しです！

障壁が閉じたままの原因を見つけました。重要な計算をする**スクリプトが見つかりません**。

コード用フォルダーに `divideByTwo.js` を作成してください。今回は次のように、実行時に**コマンドライン引数**を受け取る必要があります。

```bash
node divideByTwo.js 48
```

スクリプトは渡された数値を 2 で割り、`console.log` で結果を出力します。難しいときはヘルプタブの**ひな型コード**を使ってください。

準備できたら、*ハック*をクリックしてレーザーを制御する関数を書き換えましょう。
