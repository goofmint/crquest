# かすかなブーンという音

<div class="aside">
<h3>やること</h3>
<ul>
  <li><code>fizzBuzz.js</code> というファイルを作成する。</li>

物の少ない植物学ラボの一角に、ほこりをかぶった宝箱がありました。長い間開かれていない様子で、中身が気になります。

鍵を調べると、内部の判定処理が壊れているようです。正しく動くプログラムに置き換えれば、鍵が開くかもしれません。

## 宝箱の鍵を修理する

コード用フォルダーに `fizzBuzz.js` を作成します。プログラムは整数を 1 個、コマンドライン引数として受け取ります。実行例です。

```bash
node fizzBuzz.js 15
```

渡された数値に応じて、次の 4 種類の値のうち 1 つを出力してください。文字列は英語のまま出力します。

| 入力値 | 出力値 |
| --- | --- |
| 3 で割り切れる | "Java" |
| 5 で割り切れる | "Script" |
| 3 と 5 の両方で割り切れる | "JavaScript" |
| 3 でも 5 でも割り切れない | 入力した数値 |

具体例です。

* 引数が `3` なら `Java` を出力する。
* 引数が `5` なら `Script` を出力する。
* 引数が `15` なら `JavaScript` を出力する。
* 引数が `7` なら `7` を出力する。

仕様どおりにプログラムが動いたら、*ハック*をクリックしてください。
