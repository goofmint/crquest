植物学者の手前にある最後の橋も無効になっています。西の橋と同じように、**樹木生命検知器**の設定が不十分で動かないようです。

橋を延ばすため、今回は検知器のスクリプトを改良しましょう。

## 改良版の樹木生命検知器

コード用フォルダーに `enhancedLifeDetector.js` を作成します。プログラムが受け取る**コマンドライン引数**は、木の状態を表す `Number` です。それに対応する文字列を出力してください。

`alive` と `other` に加えて、木の状態 ID と表示する文字列との対応表が近くにあります。

| 木の状態 ID | 木の状態 |
| --- | --- |
| 0 | "alive" |
| 1 | "flowering" |
| 2 | "shedding" |
| 3+ | "other" |

実行時に渡された ID を調べ、対応する文字列を表の英語のまま出力します。たとえば次のように実行した場合は、

```bash
node enhancedLifeDetector.js 2
```

`shedding` を出力します。0、1、2 以外の数値が渡された場合は `other` を出力してください。

これまでより複雑なブール論理が必要です。詳しくは**ヘルプ**を参照してください。

`enhancedLifeDetector.js` が仕様どおりに動いたら、*ハック*をクリックして確認しましょう。
